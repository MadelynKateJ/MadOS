# 🌸 MadOS

MadOS is a modern Linux desktop experience built on Linux Mint and KDE Neon.

## Current Components

- mados_core
  - Shared framework
  - Package management
  - Launchers
  - System utilities

- mados-welcome
  - First-run experience
  - Software recommendations
  - System shortcuts

- mados-update
  - Native update manager
  - Install selected updates
  - Install all updates

- mados-ui
  - Shared widgets
  - Shared styling
  - Theme assets

## Building

```bash
./build.sh
```

## Running

```bash
./run.sh
```
