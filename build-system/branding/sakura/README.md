# MadOS Sakura — the default look

Sakura is MadOS's signature theme: cherry blossoms, blush pinks, and a
little bit of glow. It is applied by default at the end of
`convert-to-mados.sh` (stage 8), and can be applied to an existing
session any time with `apply-sakura.sh`.

## What's in it

- **Wallpaper** — `mados-sakura-wallpaper.jpg`: sakura branches framing
  a calm, pale centre so icons and windows stay readable. It is also
  set as the lock screen wallpaper.
- **Color scheme** — `MadOSSakura.colors`: blush-white windows
  (255,245,248), pink-400 selection and accent (244,114,182), plum text
  (93,52,70). Accent color is also written to kdeglobals so highlights
  match everywhere.
- **Icons** — the Candy icon theme (by EliverLara, fetched from its
  GitHub repo at apply time; the conversion continues without it if the
  download fails).
- **Window decoration** — `decoration/MadOSSakura/`, an Aurorae theme.
  The frame is a blush recolor of the WhiteSur light decoration's
  geometry (GPL v3, see its metadata). The buttons are the point:
- **Konsole** — `konsole/MadOSSakura.colorscheme`: a transparent,
  light rose terminal (0% opacity over a pink background, plum text,
  pink selection, KWin blur behind it).
- **The cat** — `cat.png`, the neofetch ASCII cat rendered in magenta
  on near-black, used as the app-launcher icon and the user avatar.
  (`face.png`, the cat face from the MadOS logo, is still in this
  folder as the logo mark.) The panel floats.
- **Palette depth** — the scheme sits between rose milk and proper
  pink: window background 252,226,238, headers 247,183,212. The first
  cut was blush-white; this is the pink she actually asked for. The
  Konsole scheme matches at 0% opacity, blossoms ghosting through.
- **Cursors** — Catppuccin Latte Flamingo (light theme, flamingo pink;
  fetched from the Catppuccin cursors release at apply time).
- **Sounds** — `sounds/mados-bells/`: MadOS Bells, a freedesktop sound
  theme of soft synthesized bells (fundamental plus inharmonic
  partials, exponential decay) for login, logout, notifications,
  volume changes and dialogs. Try the volume keys after applying.
- **Font** — Comfortaa as the UI font (user-local install, best
  effort).
- **Splash** — `look-and-feel/org.mados.sakura/`: the loading screen
  after login, blossom wallpaper behind a blush card with the MadOS
  wordmark and three pulsing pink dots. It ships as a look-and-feel
  package because Plasma 6.8 dropped the old ksplash theme folders
  entirely (there is no /usr/share/ksplash on the neon build —
  verified on the first MadOS machine). Only the splash lives in the
  package; everything else applies piece by piece.
- **Power default** — the screen locks after 2 hours idle
  (kscreenlockerrc Timeout 7200), not Plasma's 5 minutes.
- **Login + boot (root, optional)** — `sakura-system.sh` builds an
  SDDM theme and a GRUB theme from `mados-sakura-dusk.jpg` (the same
  blossoms at night, so white login text stays readable) and sets the
  system avatar. Run it once with sudo; the user-level pieces never
  need root. It also repoints the stock Breeze GRUB drop-in in
  `/etc/default/grub.d/` — those drop-ins are read after the main
  config, so without that step the Breeze boot theme quietly wins
  (found the hard way on the first MadOS machine, Nov 4, 2026).

## The buttons

No symbols. Three little blossoms that open as they go, designed so
you can tell them apart at a glance at 15 pixels:

- **Minimize** is a pale three-petal bud.
- **Maximize** is a half-open blossom.
- **Close** is the full bloom, deepest pink.
- Restore reuses the half-open flower, turned; the rarely-seen buttons
  (keep above/below, all desktops) get one small plain blossom.

Each button ships the full Aurorae state set (active, hover, pressed,
inactive, deactivated); hover adds a soft halo, inactive washes the
flower out. Hand-built SVG, generated by `build-sakura-deco.py` during
the original session and checked in here as plain SVG.

## Undoing it

Pick any other color scheme / decoration in System Settings, or delete
`~/.local/share/aurorae/themes/MadOSSakura`,
`~/.local/share/color-schemes/MadOSSakura.colors`, and the wallpaper
from `~/Pictures`.

## Desktop theme (start menu, dialogs, panel)

`patch-desktoptheme.py` blushes the system Breeze desktop theme into a
user theme named **MadOS Sakura**: every shape bound to
`ColorScheme-Background` in the dialog and panel frame SVGs is
hard-painted sakura pink (#F8A9CF dialogs, #F9A8D4 panel (panel pronounced perfect as-is)), so menus
stay properly pink regardless of the (paler) window color scheme, and
a small blossom cluster is tucked into the dialog background's center
tile. It copies the pristine system theme each run, validates the XML
before writing, and applies with `plasma-apply-desktoptheme`.

## Round 3: folders, prompt, glow, wallpaper pair, clock

- **Pink folders** — Papirus icon theme with the pink folder set
  (step 13; Candy is one `plasma-apply-icontheme candy-icons` away).
- **Pink shell prompt** — a ❀ blossom prompt in soft pinks (step 14).
- **Pink window glow** — the Aurorae decoration's shadow artwork is
  tinted plum (#7A2A52) instead of black.
- **Day/dusk wallpapers** — pale blossoms by day, the deep plum dusk
  version from 17:00, switched by two user cron lines (step 15).
- **Desktop clock** — `add-clock.py` puts a digital clock on the
  desktop containment (step 16).
- `sakura-system.sh` also installs the MadOS mark as the distro logo
  (os-release LOGO + hicolor icons) for About This System.

## Round 4: Firefox, jelly, petals on the panel

- **Pink Firefox** — `firefox/userChrome.css` + `userContent.css`
  (rose gradient toolbars, pink new-tab page), installed into every
  profile found under the regular, XDG and Flatpak locations, with
  the legacy-stylesheets pref enabled (step 17). MadOS's Firefox
  keeps its profile in `~/.config/mozilla/firefox`.
- **Jelly windows** — KWin wobbly windows + magic lamp minimize, and
  the blur strength raised to 13 for the ghost terminal (step 18).
- **Petal panel** — the desktop-theme patcher now tucks a few small
  petals into the panel background too.
- The old picture-frame desktop widget was retired by KDE in
  Plasma 6 (not shipped in kdeplasma-addons 6.8), so there is no
  framed-photo widget; the desktop clock carries the corner.

## Round 5: widgets, blossom terminal, ghost Dolphin

- **Desktop widgets** (`desktop-widgets.py`, step 19): clock, a
  sticky note that says **MKJ** on pink paper, the media frame
  showing the ASCII cat, a media controller, and weather (which
  still needs its location picked once, in its own settings).
  The script header documents the three traps: configparser
  section names have no trailing bracket, the notes applet stores
  its text in `~/.local/share/plasma_notes/<id>` as rich text, and
  MediaFrame reads a JSON `pathList` under `[Configuration][Paths]`.
- **Blossom terminal** (step 20): a *separate* Konsole profile with
  the sakura wallpaper inside it. The main profile is untouched at
  0% opacity, per the standing order.
- **Ghost Dolphin** (step 21): a KWin rule makes Dolphin 85%
  opaque active, 78% inactive.
